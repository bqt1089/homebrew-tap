# bqt1089/homebrew-tap

Homebrew tap for [UsagePet](https://github.com/bqt1089/UsagePet), a pixel pet widget for your Claude Code usage limits.

```sh
brew install --cask bqt1089/tap/usagepet
```

Upgrade: `brew upgrade --cask usagepet` · Uninstall: `brew uninstall --cask usagepet`

UsagePet is not notarized yet: on first launch open **System Settings → Privacy & Security → Open Anyway**.

The cask is updated automatically by UsagePet's release workflow.
